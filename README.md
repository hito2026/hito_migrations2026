# hito_migrations2026

Sitio interno de seguimiento de las migraciones de Odoo 17 → 19.

La página está **protegida con clave** y su contenido viaja cifrado (AES + PBKDF2):
el código publicado no contiene texto del proyecto ni credenciales.

Página: https://hito2026.github.io/hito_migrations2026/

Este repositorio solo contiene los archivos del sitio. El detalle técnico de cada caso
vive en los repositorios internos de migración y en el caso de Odoo correspondiente.
